# 頭沐 行銷助手：部署步驟（第 1 步：試算表與設定頁）

行銷助手和任務系統、財務系統分開：另一份 Google Sheet、另一個 Apps Script。登入方式和任務系統一樣用「姓名 ＋ PIN」，但帳號是行銷助手自己的，和任務系統不共用。

網址：`https://torikuo314.github.io/chiefrom.hair/marketing/`

## 1. 建立行銷助手專用的 Google Sheet 與後台

1. 用 Tori 的 Google 帳號開一份新的 Google Sheet，命名「頭沐 行銷助手」。**不要分享給任何人**。
2. 「擴充功能 → Apps Script」，刪掉預設程式碼，貼上 `marketing/apps-script/Code.gs`，存檔。
3. 函式選單選 `setup`，按「執行」，照畫面授權（會要求 Sheet、Drive 兩種權限）。
4. 執行完打開「執行記錄」，會看到 `管理者初始 PIN：xxxxxxxx`。先記下來，登入後馬上改掉。
5. Sheet 會多出這些分頁，並匯入規格書第 9 節的資料：
   - 設定（品牌資料、各平台規則、法規紅線、作者小檔案、Tori 口吻、反 AI 感規則、花費上限…）
   - 門市（3 間）、關鍵字庫（30 組）、禁用詞、獎品清單、遊戲主題表（12 個月）、挑戰主題（8 個）
   - 人員（先只有管理者 Tori）、定稿範例、脆素材庫（空的，等 Tori 補）
   - 內容、脆問答、對比照、每月活動、用量紀錄（後面步驟才會用到，先建好欄位）
   - 雲端硬碟會多一個「頭沐 行銷助手 對比照」資料夾（不公開分享）

`setup` 可以重跑：只補缺少的分頁和設定項目，不會覆蓋已經改過的資料，也不會重設管理者 PIN。

PIN 只存雜湊值，連 Sheet 裡也看不到明碼。「人員」分頁裡的 PIN 雜湊、salt 等欄位不要手動改。

## 2. 部署

1. Apps Script「部署 → 新增部署作業 → 網頁應用程式」，執行身分「我」，存取權「任何人」。
   - 「任何人」只代表網址連得到。除了登入畫面要用的名單（只有姓名和門市），每個動作都要先用 PIN 登入，後台才會回應。
2. 把網址貼到 `marketing/index.html` 最上面的 `const SCRIPT_URL="";` 引號裡，推上 GitHub。

改了 `Code.gs` 之後要「部署 → 管理部署作業 → 編輯 → 版本選新版本」，網址才會用到新程式。

## 3. 改 PIN、新增員工

1. 用管理者帳號登入，到「設定 → 人員與 PIN」，點 Tori 那一列，在「新 PIN」填你自己記得的 PIN，儲存後用新 PIN 重新登入。
2. 按「＋ 新增」，填姓名、所屬門市、PIN（6–12 位數字），私下告訴本人。

## 忘記管理者 PIN

打開 Apps Script 編輯器，執行 `resetAdminPinFromEditor`，到「執行記錄」看新的 PIN。只有能開這份 Sheet 的帳號才做得到。

## Claude API 金鑰

1. 在 https://platform.claude.com 登入，Settings → Billing 儲值；Settings → Limits 設每月花費上限。
2. Settings → API Keys 建立金鑰（選「其他地方」，到期時間選永不過期）。
3. Apps Script「專案設定 → 指令碼屬性」新增 `ANTHROPIC_API_KEY`，值貼金鑰。**不要**放在試算表、程式碼或 GitHub。
4. 在編輯器執行 `testAI`，執行記錄出現「AI 回覆：連線成功」就代表金鑰、模型、付款都正常（花費不到 1 元）。

## 更新程式（每一步開發完都一樣）

1. 打開 GitHub 上最新的 `marketing/apps-script/Code.gs`，全選複製，貼到 Apps Script 取代全部舊程式，存檔。
2. 執行一次 `setup`：只會補上新的設定項目和欄位，不會覆蓋你改過的資料。如果出現授權畫面就允許。
3. 「部署 → 管理部署作業」→ 點目前那個部署的 ✏️ 編輯 →「版本」選「**新版本**」→ 部署。網址不會變。

## 驗收（第 1 步）

- PIN 打錯會顯示「帳號或 PIN 不正確」；同一帳號連續錯 5 次鎖 15 分鐘。
- Tori 登入後有「產出、審稿、對比照、設定」四頁；設定頁可以改品牌資料、各平台規則、關鍵字、禁用詞、門市、員工、獎品、每月主題、花費上限，改完重新整理還在，Sheet 裡也看得到。
- 「設定 → 待補」列出還沒補的資料（預約連結、官網網址、文章網址格式、回留訊息公版、定稿範例、員工名單、7 月主題、中等獎品）。
- 「設定 → 禁用詞試檢查」貼「完全不傷髮」會被標出來。
- 員工登入只看到「對比照」一頁；直接呼叫設定相關的 API 一律回傳 `FORBIDDEN`。
- 員工被重設 PIN、停用或刪除後，已登入的畫面下一個動作就會被登出。
- 瀏覽器開發者工具的「網路」分頁裡找不到任何人的 PIN。

本機測試（不需要 Google 帳號）：

```bash
node marketing/apps-script/test/marketing.test.js
```

## 驗收（第 2 步：官網文章）

- 「產出」頁顯示本月花費、模型名稱；關鍵字第一個（★）是依當月、優先序、最久沒用選出的建議。
- 按「產出官網文章」約 1～3 分鐘後出現文章、Meta 描述、網址代稱、配圖建議、內部連結建議、FAQ 與作者的結構化資料。
- 沒提供現場觀察的地方標「待素材」，沒有編造客人的話或數據。
- 法規自檢：禁用詞和 AI 判斷有疑慮的句子在文章裡標黃，並列出原因與建議寫法；下方固定顯示「這是系統檢查，不等於法律意見，發布前請再看一次。」
- 失敗時（金鑰錯、餘額不足、Claude 忙碌、逾時）顯示清楚原因，可以一鍵重產。
- 每次呼叫都記在「用量紀錄」；本月估算花費達到「設定 → AI 與費用」的上限就停止產出。

## 驗收（第 3 步：審稿區）

- 「審稿」頁可以依 待審／已核可／已發布／全部 篩選，列出標題、負責人、待素材數、建議或實際發布日。
- 點開一篇可以：直接改標題和內文、改建議發布日、改負責人、一鍵複製（含格式或 Markdown）。
- 狀態：待審 →「核可」→ 已核可 →「標記已發布」（記錄發布日）→ 已發布；可以退回待審。核可後再改字會自動退回待審。還有待素材或法規提醒時，核可前會再問一次。
- 補素材：每個【待素材】有一個輸入框，按「補進文章」後 AI 只替換那幾處，其他文字一字不動；補的內容也存進文章素材庫。
- 請 AI 重寫：可以附一句修改指示；不會新增 Tori 沒提供的經歷，還沒補的待素材會保留。
- 直接改字後禁用詞馬上重新比對，AI 語意檢查可以按「重新做 AI 檢查」；AI 重寫、補素材完成後會自動重做檢查。
- AI 處理失敗時文章不會被改動，畫面會說明原因，可以再試。

## 驗收（第 4 步：Google 商家、IG 限動）

- 「產出」頁的 Google 商家：選一篇官網文章（或只選關鍵字），一次產出三間店各一篇，每篇挑不同重點，建議發布日週二。審稿畫面上方可切換三間店；下方顯示「預約」按鈕要貼的連結。
- 格式檢查（不花 AI 費用）：內文有電話號碼、高雄兩間店沒提醒預約時選對店，會在法規自檢裡標出來。
- IG 限動：一次產出互動型、知識型、髮色對比型三組，每組 2～4 頁，每頁有主文字、建議畫面、互動貼圖；建議發布日週一、三、五。主文字超過 15 字、沒有導向預約會被標出來。
- 三則共用一次產出；產出失敗時三則都標失敗，可以一鍵重產。
- 審稿區的直接改字、潤飾、重寫、補素材、套用建議、還原、核可與已發布，三種內容都能用。
